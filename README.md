# Variadic Macro in C

A simple C program that demonstrates a variadic macro using `__VA_ARGS__`.
It allows a macro to accept a variable number of arguments.

## File

variadic_macro.c

## How to Run

gcc variadic_macro.c -o variadic_macro
./variadic_macro
